## 👋 About

I build production-ready mobile and web apps for African markets: offline-first, secure by default, with mobile-money payments (MTN MoMo, Airtel Money). I ship to the App Store and Google Play, and I teach what I learn.

- **Co-Founder**, Chadito (classifieds marketplace for Chad)
- **Founder**, Nour Dev TD (freelance mobile & web studio)

## 🔭 Current focus

- 🛠️ Building **Griot**: an AI-powered portfolio platform for African developers
- 📱 Scaling **Pro Rently**, **TauxLive** and **Chadito**; maintaining **QuickBill**
- 📚 Learning: advanced Next.js patterns, networking & cybersecurity (Kali Linux), Kinyarwanda
- 🎯 Open to freelance clients worldwide and to funded Master's programs in Software Engineering
- 💬 Ask me about: React Native performance, strict TypeScript, Supabase RLS, publishing apps to the stores

## 🧭 Engineering principles

- 🛡️ **Zero `any`**: strict TypeScript everywhere. Fewer runtime errors, better DX.
- 🔒 **Security by default**: Supabase Row Level Security on every table, no exceptions.
- 📶 **Offline-first**: SQLite locally, synced to Supabase when online. Built for unreliable networks.
